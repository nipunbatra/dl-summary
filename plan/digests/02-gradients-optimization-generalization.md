## Lecture 5: Optimization I. Gradient estimates and step sizes

**Aim.** Decide how much data measures each gradient, show that a sampled gradient is an unbiased but noisy estimate, and show that even an exact gradient can zigzag when one learning rate must serve directions of very different steepness.

**Running examples.**
- *Example A, four-point line fit*: $\hat y=b+wx$ on $(-1,-1),(0,1),(1,3),(2,6)$, $\ell_i=\tfrac12(\hat y_i-y_i)^2$, start $\boldsymbol\theta_0=(b,w)=(2,-1)$, $\eta=0.1$. Per-example gradients at $\boldsymbol\theta_0$: $(4,-4),(1,0),(-2,-2),(-6,-12)$. Least-squares optimum $\boldsymbol\theta^*=(1.1,2.3)$.
- *Example B, scaled-feature regression*: $\hat y_i=\theta_1x_{i1}+\theta_2x_{i2}$, rows $(x_{i1},x_{i2},y_i)=(-1,-10,4),(-1,10,-6),(1,-10,6),(1,10,-4)$, generated by $\boldsymbol\theta^*=(1,-0.5)$. Full loss $\mathcal L=\tfrac12(\theta_1-1)^2+50(\theta_2+0.5)^2$, start $\boldsymbol\theta_0=(-1.4,0.35)$, $\eta=.0195$. Called a *ravine*: "one direction is $100\times$ steeper" (S05).
- A third set, "standardized, but still correlated": $x_{\cdot1}=(-1,-1,1,1)$, $x_{\cdot2}=(-7/5,-1/5,1/5,7/5)$, correlation $4/5$, $\mathbf H=\begin{pmatrix}1&4/5\\4/5&1\end{pmatrix}$, moves $(a,a)$ vs $(a,-a)$ change the loss by $\tfrac95a^2$ vs $\tfrac15a^2$ ("a factor of nine").

**Ideas in teaching order.**
1. "Backprop measured the slope; today we decide how to move": $\boldsymbol\theta_t\to$ forward $\to\mathcal L\to$ backward $\to\mathbf g_t\to$ optimizer $\to\boldsymbol\theta_{t+1}$.
2. Vanilla GD as a four-line loop; full-batch gradient on Example A.
3. The training clock: epoch, iteration, update; $K=\lceil N/B\rceil$ iterations per epoch.
4. SGD: $I_t\sim\text{Uniform}\{1,\dots,N\}$, $\hat{\mathbf g}_t=\nabla\ell_{I_t}(\boldsymbol\theta_t)$; one valid draw can raise the full loss.
5. Minibatch as "the useful middle ground"; averaging cancels some disagreement between per-example loss surfaces.
6. Estimator language: unbiased means $\mathbb E[\hat{\mathbf g}_t\mid\boldsymbol\theta_t]=\mathbf g_t$; larger $B$ keeps the centre and shrinks the spread.
7. "An exact gradient can still be slow": Example B ravine, one correct step overshoots across the valley; small vs large $\eta$ trade-off.
8. Fix geometry first: standardizing $x_2$ removes the ravine; correlated features still give a tilted ravine.

**Key equations.**
$$\mathcal L(\boldsymbol\theta)=\frac1N\sum_{i=1}^N\ell_i(\boldsymbol\theta),\qquad \boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\eta\,\mathbf g_t$$
$$\hat{\mathbf g}_t=\frac1{B_t}\sum_{i\in\mathcal B_t}\nabla_{\boldsymbol\theta}\ell_i(\boldsymbol\theta_t),\qquad K=\lceil N/B\rceil$$
$$\mathbb E[\hat{\mathbf g}_t\mid\boldsymbol\theta_t]=\sum_{i=1}^N\frac1N\nabla_{\boldsymbol\theta}\ell_i(\boldsymbol\theta_t)=\mathbf g_t,\qquad \mathbb E[\Delta\boldsymbol\theta_t\mid\boldsymbol\theta_t]=-\eta\,\mathbf g_t$$
$$\nabla_\theta\mathcal L(\boldsymbol\theta)=(\theta_1-1,\;100(\theta_2+0.5))$$

**Worked numbers worth reusing.**
1. Full batch on Example A: $\mathbf g_0=\tfrac14[(4,-4)+(1,0)+(-2,-2)+(-6,-12)]=(-0.75,-4.5)$, $\boldsymbol\theta_1=(2.075,-0.55)$, $\mathcal L:7.125\to\approx5.215$ (slides "Example A: compute one full-batch gradient", "Average, then update").
2. Bad SGD draw $I_0=2$: $\hat{\mathbf g}_0=(1,0)$, $\boldsymbol\theta_1=(1.9,-1)$; $\ell_2:0.500\to0.405$ but $\mathcal L:7.125\to7.205$ ($\Delta\mathcal L=+0.320/4=+0.080$) ("Unbiased means correct on average").
3. Minibatch $\{1,2\}$: $\hat{\mathbf g}_0=(2.5,-2)$, $\boldsymbol\theta_1=(1.75,-0.8)$.
4. Ravine first step: $\mathbf g_0=(-2.4,85)$, $\Delta\boldsymbol\theta_0=-.0195(-2.4,85)=(.0468,-1.6575)$, $\boldsymbol\theta_1=(-1.3532,-1.3075)$, crossing $\theta_2^*=-.5$ ("One correct step can overshoot across the valley").
5. Mean of the four one-example updates $=(0.075,0.450)=\Delta\boldsymbol\theta_\text{full}$.

**Code** (L5 deck, "Choosing the batch size in PyTorch").
```python
loader = DataLoader(dataset, batch_size=B, shuffle=True)

for epoch in range(E):
    for xb, yb in loader:          # one iteration / minibatch
        optimizer.zero_grad(set_to_none=True)
        pred = model(xb)
        loss = 0.5 * (pred - yb).square().mean()
        loss.backward()            # gradient of this batch mean
        optimizer.step()           # one parameter update
```

**The lecture's own summary lines.**
- "The gradient is a measurement. An optimizer turns it into $\Delta\boldsymbol\theta_t:=\boldsymbol\theta_{t+1}-\boldsymbol\theta_t$."

**Three exam-style questions.**
1. *Conceptual.* SGD with uniform sampling is unbiased. Why can a single SGD step still increase the full training loss? *Answer:* unbiasedness fixes only the average over draws, $\mathbb E[\hat{\mathbf g}_t\mid\boldsymbol\theta_t]=\mathbf g_t$; one draw follows one example's surface (row 2 lowered $\ell_2$ by 0.095 yet raised $\mathcal L$ by 0.080).
2. *Conceptual.* With $N=4$, $B=2$, how many updates per epoch, and why compare runs by updates or examples rather than epochs? *Answer:* $K=\lceil4/2\rceil=2$. Different $B$ gives different update counts per epoch, so epochs alone hide the optimiser's actual work.
3. *Numeric.* Example A at $\boldsymbol\theta_0=(2,-1)$, $\eta=0.1$, minibatch $\{3,4\}$. Find $\boldsymbol\theta_1$. *Answer:* $\hat{\mathbf g}_0=\tfrac12[(-2,-2)+(-6,-12)]=(-4,-7)$; $\boldsymbol\theta_1=(2,-1)-0.1(-4,-7)=(2.4,-0.3)$. Residuals become $(3.7,1.4,-0.9,-4.2)$, so $\mathcal L=\tfrac18(34.1)=4.2625<7.125$.

## Lecture 6: Backpropagation and autograd from scratch

**Aim.** Show that every scalar operation passes back "downstream gradient = upstream gradient × local derivative", that branches add, and that one reverse sweep through the recorded graph returns every parameter's derivative.

**Running examples.**
- *Central graph*: $\hat y=wx+b$, $\mathcal L=(\hat y-y)^2$ with $(w,x,b,y)=(2,3,1,10)$, broken into primitives $m=wx$, $a=m+b$, $e=a-y$, $\mathcal L=e^2$. Forward: $m=6$, $a=7$, $e=-3$, $\mathcal L=9$.
- *Branch*: $u=x^2$, $v=3x$, $\mathcal L=u+v$ at $x=4$ (nudge $4\to4.01$ gives $0.08+0.03$).
- Single-node drills: square $v=u^2$ at $u=3$ with arriving $7$ gives $42$; multiply $a=2,b=5$, arriving $3$ gives $15$ and $6$; inactive ReLU $u=-2$, arriving $5$ gives $0$.

**Ideas in teaching order.**
1. Vocabulary: forward computes values, backward computes sensitivities; graph legend (white leaf, gray stored value, blue operation box, orange loss).
2. One derivative, three routes: symbolic, finite difference, reverse-mode AD; "Symbolic to reason · finite differences to check · reverse mode to train."
3. Gradient checking: central difference $g_\text{FD}$ in float64 against autograd.
4. One local rule, colour-coded upstream (teal), local (blue), downstream (orange).
5. Rule table: add copies, multiply scales by the other input, square uses $2u$, activation uses $\phi'(u)$; "Use `+=`, not `=`".
6. Branches accumulate: multivariable chain rule sums every path.
7. Central worked example forward then backward, verified symbolically and with PyTorch `retain_grad()`.
8. Read the sign: $\partial\mathcal L/\partial w=-18$ means increase $w$; one step with $\eta=0.01$.
9. Autograd lifecycle: `Tensor`, `grad_fn`, `L.backward()`, `p.grad`, `retain_grad()`, `opt.zero_grad()` ("reverse mode = direction · backprop = algorithm · autograd = engine: record → save → replay").

**Key equations.**
$$\frac{\partial\mathcal L}{\partial u}=\frac{\partial\mathcal L}{\partial v}\cdot f'(u)\quad\text{for }v=f(u)$$
$$\frac{\partial\mathcal L}{\partial x}=\sum_{i=1}^k\frac{\partial\mathcal L}{\partial u_i}\frac{\partial u_i}{\partial x}$$
$$g_\text{FD}=\frac{\mathcal L(\theta_j+\epsilon)-\mathcal L(\theta_j-\epsilon)}{2\epsilon}$$
$$\theta_{j,t+1}=\theta_{j,t}-\eta\,\frac{\partial\mathcal L}{\partial\theta_j}$$
(S06 shorthand: $g_u=\partial\mathcal L/\partial u$; table rows $g_a\mathrel{+}=g_v,\ g_b\mathrel{+}=g_v$ for add; $g_a\mathrel{+}=g_vb$ for multiply; $g_a\mathrel{+}=g_v,\ g_y\mathrel{-}=g_v$ for subtract.)

**Worked numbers worth reusing.**
1. Full backward on the central graph: seed $g_\mathcal L=1$; $g_e=2e=-6$; $g_a=-6$, $g_y=6$; $g_m=-6$, $g_b=-6$; $g_w=g_mx=-18$, $g_x=g_mw=-12$. Final $\partial\mathcal L/\partial(w,b,x,y)=(-18,-6,-12,6)$ (slides "Backward: ..." through "All stored values and their gradients").
2. Branch: $(\partial\mathcal L/\partial x)_{\text{via }u}=1\cdot2x=8$, via $v$ $=3$, total $11=2(4)+3$.
3. One update: $\eta=0.01$, $w:2\to2.18$, $b:1\to1.06$, prediction $7\to7.60$, loss $9\to5.76$.
4. Depth: local slope $0.5^{10}\approx0.001$, $1^{10}=1$, $1.5^{10}\approx57.7$; sigmoid factor at most $1/4$ per layer.

**Code.**
Slides, "PyTorch adds the same two paths":
```python
x = torch.tensor(4.0, requires_grad=True)
u = x**2                 # path 1
v = 3*x                  # path 2
L = u + v
L.backward()

print(x.grad)            # tensor(11.)
```
The from-scratch scalar engine is **not on the slides**; it lives in the linked Colab `notebooks/L03/04_scalar_autograd_pytorch_to_scratch.ipynb` (classes `ParentLink`, `Value`; ops `multiply`, `add`, `subtract`, `square`; `dependency_safe_order`; `backward`). Its core loop, verbatim:
```python
    for output in reversed(safe_order):
        # One saved parent link gives one chain-rule update.
        for link in output.parents:
            parent = link.value
            upstream = output.grad
            local = link.local_grad
            contribution = upstream * local
            before = parent.grad
            parent.grad += contribution
```
and one op:
```python
def multiply(u, v, label):
    return Value(u.data * v.data, label,
                 parents=(ParentLink(u, v.data),
                          ParentLink(v, u.data)), op="×")
```

- "Seed $\partial\mathcal L/\partial\mathcal L=1$, then walk the graph backward, at each operation computing downstream gradient = upstream gradient × local derivative, and adding gradients wherever a variable branched."
- "One backward sweep produced all four partial derivatives."
- S06 banner: "Backprop is the reverse-sweep algorithm. Autograd is the engine that records operations and executes their backward rules."

**Connections.** Builds on the MLP forward map and squared-error loss from the earlier module. Feeds schedule L5 (the gradient $\mathbf g_t$ the optimiser consumes; the deck's focus slide says "Next: turn those gradients into reliable parameter updates"), schedule L8 (same rules stacked into vectors), and dropout backward in schedule L10 (mask as local factor).

**Three exam-style questions.**
1. *Conceptual.* Why must a node's gradient be accumulated with `+=`? *Answer:* a value used by several operations affects the loss through each path; the multivariable chain rule sums the path products, so `=` would keep only the last path.
2. *Conceptual.* Why train with reverse mode instead of finite differences? *Answer:* one reverse sweep returns all $P$ derivatives of a scalar loss; finite differences need $2P$ loss evaluations and are approximate, so they are for checking only.
3. *Numeric.* Same graph with $(w,x,b,y)=(1,2,3,4)$. *Answer:* forward $m=2$, $a=5$, $e=1$, $\mathcal L=1$. Backward $g_e=2$, $g_a=2$, $g_y=-2$, $g_m=2$, $g_b=2$, $g_w=g_mx=4$, $g_x=g_mw=2$.

## Lecture 7: Optimization II. Momentum, RMSProp and Adam

**Aim.** Build optimiser memory from one primitive, the EWMA: momentum averages signed gradients (direction), RMSProp averages squared gradients (per-coordinate scale), Adam does both with bias correction.

**Running examples.**
- *Temperature signal*: constructed 120-day series, fixed seed 12, smoothed with $\beta=.5,.9,.98$; zero-start bias with $x_1=17.968\,^\circ$C.
- *Example B ravine* again (start $(-1.4,.35)$, $\mathbf g_0=(-2.4,85)$, $\mathcal L(\boldsymbol\theta_0)=39.005$). Rates: GD $\eta=.0195$; momentum $\eta=.0195$, $\beta=.25$; RMSProp $\eta=.08$, $\beta_2=.9$; Adam $\eta=.10$, $\beta_1=.9$, $\beta_2=.999$ (55-update comparison).
- *Scalar check*: $\mathcal L(\theta)=\tfrac12\theta^2$, $\theta_0=2$, $g_0=2$, $\eta=.10$, $\beta=.5$, $\beta_2=.9$, $\epsilon_\text{opt}=0$.

**Ideas in teaching order.**
1. Noisy readings; short memory follows noise, long memory lags.
2. EWMA $m_t=\beta m_{t-1}+(1-\beta)x_t$; weights $(1-\beta)\beta^k$ by repeated substitution.
3. Zero start biases early estimates low; divide by the weight that has arrived, $1-\beta^t$.
4. Momentum "asks one question: Is this direction consistent over time?"; boxed update; worked six steps vs GD.
5. Coordinate view: in $\theta_1$ old and new pushes add, in $\theta_2$ they nearly cancel; feature standardization would also fix this example.
6. RMSProp: "Is this component large relative to its usual size?"; square, mean, root.
7. Adam = adaptive moment estimation; $\beta$ renamed $\beta_1$; bias correction uses $t+1$.
8. "Same ravine, four stored-state mechanisms"; rates are method specific and must be retuned.

**Key equations** (deck notation; $\hat{\mathbf g}_t=\nabla_{\boldsymbol\theta}\mathcal L_{\mathcal B_t}(\boldsymbol\theta_t)$).
$$\mathbf m_{t+1}=\beta\,\mathbf m_t+(1-\beta)\hat{\mathbf g}_t,\quad \mathbf m_0=\mathbf 0,\qquad \boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\eta\,\mathbf m_{t+1}$$
$$\mathbf v_{t+1}=\beta_2\mathbf v_t+(1-\beta_2)\hat{\mathbf g}_t^2,\quad \mathbf r_{t+1}=\sqrt{\mathbf v_{t+1}}+\epsilon_\text{opt},\quad \boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\eta\,\hat{\mathbf g}_t/\mathbf r_{t+1}$$
$$\hat m_t=\frac{m_t}{1-\beta^t}\ \text{(EWMA)},\qquad \hat{\mathbf m}_{t+1}=\frac{\mathbf m_{t+1}}{1-\beta_1^{t+1}},\quad \hat{\mathbf v}_{t+1}=\frac{\mathbf v_{t+1}}{1-\beta_2^{t+1}}$$
$$\boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\eta\,\frac{\hat{\mathbf m}_{t+1}}{\sqrt{\hat{\mathbf v}_{t+1}}+\epsilon_\text{opt}}$$
PyTorch momentum stores $\tilde{\mathbf m}_{t+1}=\beta\tilde{\mathbf m}_t+\hat{\mathbf g}_t$, so `lr` $=(1-\beta)\eta$.

**Worked numbers worth reusing.**
1. EWMA: $m_{t-1}=30$, $x_t=36$, $\beta=.9$ gives $30.6$; zero start $m_1=.1(17.968)=1.7968$, corrected $\hat m_1=17.968$.
2. First update on $\tfrac12\theta^2$: GD $\theta_1=1.80$ ($\mathcal L=1.620$); momentum $m_1=1$, $\theta_1=1.90$ ($1.805$); RMSProp $v_1=.4$, $r_1=.632$, $\theta_1=1.684$ ($1.418$) ("First update on $\mathcal L(\theta)=\tfrac12\theta^2$").
3. Momentum vs GD on Example B: $\mathbf m_1=(-1.8,63.75)$, $\boldsymbol\theta_1=(-1.3649,-.893125)$, $\mathcal L_1\approx10.524$ vs GD $35.372$; after six updates $2.303$ vs $21.794$; after 55 updates $.330$ vs $.458$. In $\theta_2$ at update 2: $-.3108+.5750=+.2642$ (pushes nearly cancel).
4. RMSProp on Example B ($\eta=.08$): $\mathbf v_1=(.576,722.5)$, $\mathbf r_1=(.759,26.879)$, $\mathbf g_0/\mathbf r_1=(-3.162,3.162)$, $\boldsymbol\theta_1=(-1.147,.097)$; update 2 gives $\boldsymbol\theta_2=(-.973,-.054)$, $\mathcal L_2=11.915$.
5. Adam on Example B: $\mathbf m_1=(-.24,8.5)$, $\mathbf v_1=(.00576,7.225)$, $\hat{\mathbf m}_1=(-2.4,85)=\sqrt{\hat{\mathbf v}_1}$, step $(.10,-.10)$, $\boldsymbol\theta_1\approx(-1.30,.25)$; update 2 with $\mathbf g_1=(-2.3,75)$ gives $\boldsymbol\theta_2=(-1.200,.151)$.

**Code** (deck, verbatim).
```python
def momentum_step(theta, grad, m, eta, beta):
    m = beta * m + (1 - beta) * grad
    theta = theta - eta * m
    return theta, m
```
```python
def adam_step(theta, grad, m, v, step, lr,
              beta1=0.9, beta2=0.999, eps=1e-8):
    m = beta1 * m + (1-beta1) * grad
    v = beta2 * v + (1-beta2) * grad.square()
    m_hat = m / (1 - beta1**step)
    v_hat = v / (1 - beta2**step)
    theta = theta - lr * m_hat / (v_hat.sqrt() + eps)
    return theta, m, v
```
```python
beta, eta = 0.25, 0.0195
opt = torch.optim.SGD(model.parameters(),
                      lr=(1-beta)*eta,
                      momentum=beta)
```

- "Momentum filters direction over time. RMSProp normalizes each coordinate by its own recent scale. Adam combines the two."

**Connections.** Directly continues schedule L5's Example B ravine and its speed vs stability trade-off. **Three exam-style questions.**
1. *Conceptual.* Why does momentum reduce zigzag across the ravine yet keep progress along it? *Answer:* the steep component's gradient reverses sign each step, so the signed average partly cancels; the shallow component keeps its sign, so contributions add.
2. *Conceptual.* Why is Adam's first step on Example B $(.10,-.10)$ regardless of gradient size? *Answer:* after bias correction $\hat{\mathbf m}_1=\mathbf g_0$ and $\sqrt{\hat{\mathbf v}_1}=|\mathbf g_0|$, so the step is $-\eta\,\text{sign}(\mathbf g_0)$ (ignoring $\epsilon$).

## Lecture 8: Vector, matrix and affine autograd

**Aim.** Name each derivative object by its shapes (derivative, gradient, Jacobian, Hessian), show that the vector chain rule is a right-to-left chain of vector-Jacobian products, and derive dense-layer and batched backward rules with shape checks.

**Running examples.**
- L3a calculus deck: $f(x)=x^2$ at $3$; bowl $x^2+y^2$ at $(3,1)$; $x^2+3y^2$; saddle $x^2-y^2$; Jacobian of $f(x_1,x_2)=(x_1^2+x_2,\ \sin(x_1x_2))$ at $(1,2)$; Hessian of $x_0^2+3x_1^2+x_0x_1$.
- L3 Part IV: $\mathbf z=(x_1+x_2,\ 2x_1-x_2)$, $J=\begin{pmatrix}1&1\\2&-1\end{pmatrix}$, upstream $\mathbf g_z=(3,4)$.
- Affine: $\mathbf x=(2,-1)$, $\mathbf w=(1,3)$, $b=0$, $z=-1$, $\mathcal L=z^2=1$.
- Dense layer: $\mathbf W=\begin{pmatrix}1&3\\-2&1\end{pmatrix}$, $\mathbf b=(0,1)$, $\mathbf z=(-1,-4)$, arriving $\mathbf g_z=(4,-2)$.
- Batch: $\mathbf X=\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$, $\mathbf Y=\begin{pmatrix}-5&-2\\7&1\end{pmatrix}$, $\mathbf Z=\begin{pmatrix}-1&-4\\5&5\end{pmatrix}$, loss $\tfrac12\|\cdot\|^2$ summed over outputs, mean over $B=2$, $\mathcal L=10$.
- Tiny MLP `nn.Linear(2, 3), nn.ReLU(), nn.Linear(3, 2)`.

**Ideas in teaching order.**
1. Derivative as local linear model, $f(x+\Delta x)\approx f(x)+f'(x)\Delta x$; gradient points uphill and is perpendicular to contours.
2. Hessian as curvature; eigenvalues classify critical points; "Elongated contours (a large condition number) make first-order gradient descent zigzag."
3. Jacobian $J_{ij}=\partial z_i/\partial x_j$: rows are outputs, columns inputs.
4. Vector chain rule $\partial\mathcal L/\partial\mathbf x=J^\top\,\partial\mathcal L/\partial\mathbf z$; "the transpose adds every output's contribution".
5. Never form $J$ ($4096\times4096\approx1.7\times10^7$ entries); compute VJPs; a non-scalar output needs a seed vector.
6. Affine node, then two neurons stacked into $\mathbf z=\mathbf W\mathbf x+\mathbf b$; shared input receives both contributions.
7. Batch: rows are examples; the middle dimension $B$ disappears in $\mathbf G_Z^\top\mathbf X$; bias gradient sums over rows; sum vs mean differ only by scale; microbatch accumulation.
8. Tiny MLP backward block by block; depth multiplies local Jacobians (vanishing and exploding).

**Key equations.**
$$\underbrace{\nabla_x\mathcal L}_{d\times1}=\underbrace{J^\top}_{d\times m}\underbrace{\nabla_z\mathcal L}_{m\times1},\qquad \nabla_x\mathcal L=J_{h_1,x}^\top J_{h_2,h_1}^\top\nabla_{h_2}\mathcal L$$
$$\mathbf g_x=\mathbf W^\top\mathbf g_z,\qquad \mathbf g_W=\mathbf g_z\mathbf x^\top,\qquad \mathbf g_b=\mathbf g_z$$
$$\mathbf Z=\mathbf X\mathbf W^\top+\mathbf 1_B\mathbf b^\top,\quad \mathbf g_W=\mathbf G_Z^\top\mathbf X,\quad \mathbf g_b=\mathbf G_Z^\top\mathbf 1_B,\quad \mathbf g_X=\mathbf G_Z\mathbf W$$
$$\mathbf g_{z_1}=\mathbf g_h\odot\mathbb 1[\mathbf z_1>0],\qquad f(x+\Delta x)\approx f(x)+\nabla f^\top\Delta x+\tfrac12\Delta x^\top H\Delta x$$
(S08 matrix mnemonic: $C=AB\Rightarrow G_A=G_CB^\top,\ G_B=A^\top G_C$.)

**Worked numbers worth reusing.**
1. VJP: $J^\top\mathbf g_z=\begin{pmatrix}1&2\\1&-1\end{pmatrix}\begin{pmatrix}3\\4\end{pmatrix}=\begin{pmatrix}11\\-1\end{pmatrix}$ (L3 "The transpose adds every output's contribution"; also S08).
2. Affine: $g_z=2z=-2$; $\partial\mathcal L/\partial\mathbf w=(-4,2)$, $\partial\mathcal L/\partial\mathbf x=(-2,-6)$, $\partial\mathcal L/\partial b=-2$.
3. Dense: neuron 1 sends $(4,12)$ to $\mathbf x$, neuron 2 sends $(4,-2)$; $\mathbf g_x=(8,10)$, $\mathbf g_W=\begin{pmatrix}8&-4\\-4&2\end{pmatrix}$, $\mathbf g_b=(4,-2)$.
4. Batch: $\mathbf R=\begin{pmatrix}4&-2\\-2&4\end{pmatrix}$, $\mathbf G_Z=\tfrac12\mathbf R$, $\mathbf g_W=\begin{pmatrix}5&-4\\-4&5\end{pmatrix}$, $\mathbf g_b=(1,1)$, $\mathbf g_X=\begin{pmatrix}4&5\\-5&-1\end{pmatrix}$.
5. L3a calculus: $f(3.1)=9.61$ vs linear $9.6$; directional derivative $4.4$ vs $\|\nabla f\|=\sqrt{20}\approx4.47$; GD $(3,1)\to(2.4,0.8)$ with $\eta=0.1$; $J(1,2)=\begin{pmatrix}2&1\\2\cos2&\cos2\end{pmatrix}$; Hessian $\begin{pmatrix}2&1\\1&6\end{pmatrix}$.

**Code.**
L3, "Under the hood: the affine backward rule" (backward method, verbatim):
```python
    @staticmethod
    def backward(ctx, grad_z):        # grad_z = dL/dz
        x, w = ctx.saved_tensors
        grad_x = grad_z * w           # dL/dx = dL/dz * dz/dx
        grad_w = grad_z * x           # dL/dw = dL/dz * dz/dw
        grad_b = grad_z               # dL/db = dL/dz * 1
        return grad_x, grad_w, grad_b # one gradient per input
```
L3a, "PyTorch: Jacobian and VJP":
```python
x = torch.tensor([1.0, 2.0], requires_grad=True)
def f(x):
    return torch.stack([x[0]**2 + x[1], torch.sin(x[0]*x[1])])
J = torch.autograd.functional.jacobian(f, x)   # full 2x2 Jacobian
v = torch.tensor([1.0, 3.0])
f(x).backward(v)                                # x.grad == J^T v  (a VJP)
```

**Three exam-style questions.**

2. *Conceptual.* In $\mathbf Z=\mathbf X\mathbf W^\top+\mathbf 1\mathbf b^\top$, why is $\mathbf g_b$ a sum over rows? *Answer:* $\mathbf b$ was broadcast to every example; each copy is a branch, so contributions add: $\mathbf g_b=\mathbf G_Z^\top\mathbf 1_B$.

## Lecture 9: Valid outputs by design and learning-rate schedules

**Aim.** Two halves: (a) let the network output unrestricted coordinates and map them into the legal set (positive scale, probability, simplex, PD covariance), with stable log-space losses; (b) choose $\eta_t$ over time, large early and smaller late, with warmup when startup is fragile.

**Running examples.**
- *Gaussian scale*: $\ell=r^2/(2\sigma^2)+\log\sigma+C$. Direct step $\sigma_0=0.1$, $\partial\mathcal L/\partial\sigma=5$, $\eta=0.1$ gives $\sigma_1=-0.4$ (L5b quiz). L5 deck version: residual $.05$, $\sigma_0=.10$, $g_0=7.5$, $\eta=.02$, proposal $\tilde\sigma_1=-.05$.
- *Logits*: BCE with $y=1$, $p=0.2$, $\eta=0.1$; softmax at $\mathbf z=(2,1,0)$, $(1000,999,998)$, $(-1000,-1001,-1002)$.
- *Covariance*: 2D target, raw $\mathbf q=(q_{11},q_{21},q_{22})$.
- *Schedules (L5c)*: bowl $\tfrac12x^2+3y^2$, start $(-2.15,0.78)$, 36 noisy SGD steps (noise $\sigma=0.48$, seed 73) with $\eta=.20$, $\eta=.04$, and cosine $.20\to.04$. L5 deck Act VIII uses Example A at $\boldsymbol\theta^*=(1.1,2.3)$ with seed 12 and 360 sampled indices.

**Ideas in teaching order.**
1. "A neural network can output values the model cannot use"; a gradient step can make $\sigma$ invalid.
2. "Correct fix: make invalid values unreachable": $\mathbf z\in\mathbb R^d\to\theta=\phi(\mathbf z)\in\mathcal C$.
3. Softplus for scales; $\text{softplus}'=\text{sigmoid}$; gentler than $\exp$ for large scales.
4. Sigmoid, odds, log-odds; BCE $=\text{softplus}(z)-yz$; stable softplus $\max(z,0)+\log(1+e^{-|z|})$; gradient $p-y$; "Train with logits".
5. Softmax lands inside the simplex; shift invariance; subtract the max; stay in log space for cross-entropy.
6. Covariance: PSD vs PD; $\Sigma=LL^\top$ with positive diagonal; pass `scale_tril`.
7. (L5 deck Act IX, overlapping) reparameterize strict interiors, project onto closed boundaries such as $[a,b]$.
8. Decay: minibatch noise $\boldsymbol\epsilon_\mathcal B$ dominates near the minimum, so shrink $\eta_t$; four time rules plus reduce on plateau; warmup then decay; name the scheduler clock.

**Key equations.**
$$\text{softplus}(u)=\log(1+e^u),\quad \sigma=\text{softplus}(u)+\epsilon,\quad \tfrac{d}{du}\text{softplus}(u)=\text{sigmoid}(u)$$
$$\ell(z,y)=\text{softplus}(z)-yz,\qquad \frac{\partial\ell}{\partial z}=p-y$$
$$\ell(\mathbf z,t)=-(z_t-m)+\log\sum_j e^{z_j-m},\quad m=\max_j z_j;\qquad \Sigma=LL^\top$$
$$g_B(\theta_t)=\nabla L(\theta_t)+\epsilon_B,\qquad \theta_{t+1}=\theta_t-\eta_t\,g_B(\theta_t)$$
$$\eta_t=\eta_0\gamma^{\lfloor t/K\rfloor},\quad \eta_t=\eta_0\exp(-kt),\quad \eta_t=\frac{\eta_0}{1+kt},\quad \eta_t=\eta_\text{min}+\frac{\eta_0-\eta_\text{min}}{2}\Big(1+\cos\frac{\pi t}{T}\Big)$$
$$\text{warmup: }\eta_t=\eta_\text{peak}\,t/W$$
Notation drift to watch: S09 writes step decay as $\gamma^{\lfloor t/S\rfloor}$, exponential as $\eta_0\gamma^t$, and cosine with $\eta_\text{max}$; the L5 deck writes inverse time as $\eta_0/(1+dt)$.

**Three exam-style questions.**

## Lecture 10: Generalization and regularization

**Aim.** Diagnose with learning curves on a clean train/validation/test contract, then add one regularizer at one site (objective, training loop, data, hidden units, targets) and let validation choose its strength.

**Running examples.**
- *Seeded 10-point regression*: $y_i=\sin(\pi x_i)+\epsilon_i$, $\epsilon_i\sim\mathcal N(0,0.25^2)$, 10 inputs evenly spaced on $[-1,1]$ (seed 21), validation at the 9 midpoints, a sealed 101-point test draw. Features $\phi(x)=(1,x,\dots,x^9)$; the degree-9 least-squares fit interpolates (train MSE $0.0000$, validation MSE $1.70$, "27 × worse" than $\sigma^2=0.0625$). - *Dropout*: $\mathbf h=(2,4,6,8)$, mask $\mathbf m=(1,0,1,0)$, $q_\text{keep}=0.5$.
- *Label smoothing*: 5 classes $\{a,b,c,d,e\}$, correct class "b", $\epsilon=0.1$.
- *CIFAR-10 controlled run*: 2,000 training examples, 5,000 validation, 10,000 test, a 666,538-parameter CNN, 35-epoch budget, one seed.
- Augmentation and Mixup use course-generated cat, cat/dog, cyclist, birdsong/rain and driving images.

**Ideas in teaching order.**
1. "Training loss does not measure generalization"; learning curves; split jobs (train fits $\theta$, validation chooses the recipe, test used once).
2. Degree-9 interpolation; reading curves (high/high underfit, low/much higher overfit); bias, variance, noise decomposition.
3. Weight decay changes the objective; interpolant has large coefficients; sweep $\lambda$ on a log scale and pick by validation; "shrink first, then fit".
4. Early stopping: $t^\star=\arg\min_t\mathcal L_\text{val}(\mathbf w_t)$, patience, restore the best checkpoint.
5. Augmentation: one stored example becomes many valid views; keep, update or reject the target; boxes, keypoints, NER spans, timestamps move with the input; input noise as local augmentation; RandAugment $N$, $M$.
6. Mixup and CutMix mix inputs and targets; three questions before using Mixup (the left turn + right turn is not "go straight").
7. Dropout: road-closure story, mask and $1/q_\text{keep}$ scaling, expectation, backward through the mask, eval mode is the identity.
8. Label smoothing gives a finite target confidence.
9. Practice: five intervention sites, workflow, CIFAR-10 ablation, test once; optional AdamW.

**Key equations.**
$$\mathbb E_{\mathcal D,\epsilon_\text{test}}\big[(\hat f_d(x)-Y)^2\big]=(b_d(x))^2+\text{Var}_\mathcal D[\hat f_d(x)]+\sigma^2$$
$$\mathcal J(w)=\mathcal L_\text{data}(w)+\frac{\lambda_\text{wd}}2\|w\|_2^2,\qquad \boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\eta(\mathbf g_t+\lambda\boldsymbol\theta_t)=(1-\eta\lambda)\boldsymbol\theta_t-\eta\mathbf g_t$$
$$t^\star=\arg\min_t\mathcal L_\text{val}(\mathbf w_t)$$
$$\tilde h_i=\frac{m_i}{q_\text{keep}}h_i,\quad \mathbb E[\tilde h_i]=q_\text{keep}\Big(\frac{h_i}{q_\text{keep}}\Big)+(1-q_\text{keep})\cdot0=h_i$$
$$\lambda\sim\text{Beta}(\alpha,\alpha),\quad \tilde x=\lambda x_i+(1-\lambda)x_j,\quad \tilde y=\lambda e_{y_i}+(1-\lambda)e_{y_j};\qquad \text{CutMix: }\tilde y=(1-r)e_{y_i}+re_{y_j}$$

## Module in one paragraph

Backprop measures a slope: seed $\partial\mathcal L/\partial\mathcal L=1$ and walk the recorded graph backward, multiplying the upstream gradient by each operation's local derivative and adding wherever a value branched; for vectors the local derivative is a Jacobian and each layer returns the VJP $J^\top\mathbf g$, so a dense layer gives $\mathbf g_x=\mathbf W^\top\mathbf g_z$, $\mathbf g_W=\mathbf g_z\mathbf x^\top$ and batch rows add into parameter gradients. Optimization decides how to move: a minibatch gradient is an unbiased but noisy estimate of the full gradient, and even an exact gradient zigzags in a ravine like $\tfrac12(\theta_1-1)^2+50(\theta_2+0.5)^2$ because one $\eta$ serves both directions. EWMA memory fixes this in two ways, momentum averaging signed gradients for direction and RMSProp averaging squared gradients for per-coordinate scale, and Adam combines both with bias correction; a schedule then sets the scalar $\eta_t$ (warmup, then cosine or step decay) and reparameterization keeps outputs legal (softplus scales, sigmoid and softmax on logits, $\Sigma=LL^\top$). Finally, low training loss is not generalization: read learning curves on a clean train, validation, test split and add one regularizer at one site (weight decay, early stopping, augmentation, dropout, label smoothing, Mixup), with validation choosing its strength and the test set opened once.

## The three things a student must remember

1. **Downstream = upstream × local, and branches add.** The same rule, stacked, is $J^\top\mathbf g$; every gradient has the shape of its tensor.
2. **The optimizer builds a direction, the schedule sets its size: $\boldsymbol\theta_{t+1}=\boldsymbol\theta_t-\eta_t\mathbf d_t$.** Momentum remembers direction, RMSProp remembers scale, Adam remembers both; minibatch noise and curvature are what they fight, and $\eta$ must be retuned for each method.
3. **Training fits, validation chooses, test reports once.** Diagnose with learning curves before regularizing, change one site at a time, and restore the validation-best checkpoint.
